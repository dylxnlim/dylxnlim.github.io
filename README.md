<h1>Dylan's Portfolio</h1>
<h2>Summary</h2>
A high-fidelity, interactive "Game Boy" style portfolio. I worked on this passion project to showcase my portfolio consisting of projects for Full-Stack development, IoT systems integration, and Cloud Architecture, wrapped in a pixel-perfect nostalgic UI.

<h2>Technical Stack</h2>
<h3>Frontend & Animation</h3>
<li><strong>React 19:</strong> Functional components and custom hooks for state management.</li>
<li><strong>Framer Motion:</strong> Handling drag gestures and component transitions.</li>
<li><strong>CSS3:</strong> Heavy use of Flexbox, CSS Grid, and image-rendering: pixelated for the retro aesthetic.</li>

<h3>🚀 Installation & Local Development</h3>
To run on your local machine:

<h4>Clone the repository:</h4>

```Bash
git clone https://github.com/dylxnlim/dylxnlim.github.io.git
```

<h4>Install dependencies:</h4>

```Bash
npm install
```

<h4>Launch the Dev Server:</h4>

```Bash
npm run dev
```

<h4>Build for Production</h4>:

```Bash
npm run build
```
